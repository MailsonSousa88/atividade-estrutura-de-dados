## 🔄 Atividade: Fila Circular

A atividade trabalha o conceito de **fila circular**, uma estrutura em que o último elemento volta para o início, permitindo melhor aproveitamento do espaço. É muito usada em sistemas que precisam de controle contínuo de entrada e saída.

---

## ⚙️ O que você pode fazer na Fila Circular

Aqui estão as principais operações, explicadas de forma simples:

* ➕ **Adicionar** um elemento no final da fila.
* ➖ **Remover** e retornar o primeiro elemento.
* 👀 **Consultar** o elemento que está no início.
* ❌ **Verificar se a fila está vazia.**
* 🚫 **Verificar se a fila está cheia.**
* 🔢 **Exibir quantos elementos existem na fila.**
* 📋 **Listar todos os elementos.**
* 📏 **Mostrar a capacidade máxima da fila.**
* 🧮 **Exibir quantos elementos ainda podem ser adicionados.**
